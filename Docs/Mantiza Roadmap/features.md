## 2. What Mantiza adds that Artemis does not have
- Voice input that acts while you are still speaking.
- A pattern-learning, resizable home screen widget (daily, weekly, monthly).
- A dynamic UI generated by the agent for each task.
- Lock Screen, Control Center, Action Button, Siri and Live Activity entry points.
- A consumer app on the phone itself, no computer or cable needed.

## 3. Artemis features we leave out
| Artemis feature | Why |
|---|---|
| CLI, Python SDK, AI coding tool (IDE) integration | Developer testing tools; not our audience |
| Device logs and bug diagnosis | Testing feature; iOS apps cannot read other apps' logs |
| Tap-anywhere screen control from the phone | Not allowed on iOS; only in the Mac companion |
| AndroidWorld benchmark | Android only; we build our own task suite on the top 50 apps |
